# Guillaume Walter — Portfolio

> Direction Artistique · Design Graphique · Stratégie de Marque

Site portfolio personnel officiel de **Guillaume Walter**, conçu selon les principes du *Quiet Luxury* (palette crème/ivoire/sable/taupe/nuit, typographies Cormorant Garamond & Manrope, mise en page éditoriale soignée et responsive).

---

## 📂 Structure du projet

```
guillaumewalter/
├── index.html              # Page d'accueil & portfolio complet
├── mentions-legales.html   # Mentions légales & RGPD (hébergement Vercel)
├── styles.css              # Feuilles de styles CSS (charte Quiet Luxury)
├── script.js               # Interactions, filtres de réalisations, menu & animations
├── vercel.json             # Configuration de déploiement Vercel
├── assets/                 # Visuels, typographies & photographies de réalisations
│   ├── brand/              # Logos, favicon, signatures
│   ├── framer/             # Maquettes & captures haute résolution
│   └── projets/            # Identités, packagings, éditions & créations
└── README.md
```

## 🚀 Déploiement & Hébergement

Le projet est configuré pour un déploiement instantané sur **Vercel** :
- `cleanUrls: true` pour des URLs sans extension `.html`.
- Déploiement automatique à chaque commit sur la branche `main`.
